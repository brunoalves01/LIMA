# LIMA
# 📚 Repositório de Atividades

Este repositório foi criado com o objetivo de armazenar e organizar as atividades desenvolvidas ao longo da disciplina. Cada pasta corresponde a uma atividade específica, contendo os arquivos necessários para sua realização e documentação.


## 📝 Resumo das Atividades

### 📄 S1_AT1_R1_LIMA
**Currículo em Markdown**
- Elaboração de um currículo utilizando a linguagem Markdown (`.md`), aplicando conceitos de formatação de texto e organização de informações.

### 📄 S1_AT2_R1_LIMA
**Exercícios de XML**
- **Ex1 - Cadastro de Livro:** Estrutura XML representando informações de livros.
- **Ex2 - Cadastro de Alunos:** Cadastro de estudantes utilizando XML.
- **Ex3 - Empresa:** Modelagem de dados de uma empresa em XML.
- **Ex4 - Pedido de Venda:** Estrutura de um pedido de venda contendo cliente, produtos e valores.
- **Ex5 - Cadastro de Produtos:** Organização de um catálogo de produtos em XML.
- **Ex6 - Sistema Escolar:** Estrutura de um sistema escolar com informações de alunos, turmas e disciplinas.

## 🎯 Objetivo

Manter um histórico organizado das atividades desenvolvidas durante a disciplina, facilitando consultas, revisões e acompanhamento da evolução dos exercícios.
