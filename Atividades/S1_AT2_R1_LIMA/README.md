# 🚀 Biblioteca de Linguagens de Marcação: Markdown, HTML & XML

> 🧪 Estudos em desenvolvimento 
> Repositório criado para praticar e consolidar conceitos fundamentais de estruturação de texto, páginas web e dados.

---

## 📌 Sobre o Projeto

Este repositório funciona como um laboratório pessoal de estudos cobrindo os principais termos e conceitos de três linguagens essenciais:

*   **Markdown:** Documentação rápida, escrita limpa e formatação leve.
*   **HTML5:** Estruturação semântica para a Web.
*   **XML:** Armazenamento, organização e transporte de dados estruturados.
